Job Scan Console

This console doesn’t execute scans itself. Run one any time by asking Claude to run /scan-jobs, or ask Claude to schedule automatic daily scans. Click Refresh after a scan lands.

This page needs to be served over HTTP, not opened as a file. In a terminal, from the project folder: python3 -m http.server 8642 — then open http://localhost:8642/console/. Opening this file directly (file://) can’t fetch local reports or the profile.

Welcome — let’s set you up

This console displays your job-search profile and scan reports. Neither exists yet — a two-minute setup with Claude creates both.

  1. 1

    Check prerequisites

    Claude desktop app with your Claude-Workshop folder connected, and the Indeed connector enabled. (Google Drive connector optional — only needed if your resume is a Google Doc.)

  2. 2

    Ask Claude to onboard you

    Copy this prompt and paste it into Claude:

    Follow the setup instructions in my job-scan-console folder's CLAUDE.md and onboard me.
  3. 3

    Refresh this page

    When Claude finishes, your profile appears here — then run your first scan by asking Claude: /scan-jobs.
